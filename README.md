# あそび2人用

iPhone 1台をふたりで使って遊べるゲーム集です。ブラウザ (Safari) だけで動き、インストールは不要です。

| ゲーム | 内容 |
| --- | --- |
| ヨット | サイコロ5つ・3回まで振って12の役を埋める。上段63点以上で+35点ボーナス |
| ヒット&ブロー | おたがいに秘密の色4つを決めて交互に推理。6色/8色、同色あり/なしを選べる |
| 五目並べ | 15路盤。禁じ手なし / 禁じ手あり (黒の三三・四四・長連) を選べる。2回タップで確定 |
| リバーシ | 置ける場所の表示、自動パス |
| チェス | キャスリング、アンパッサン、昇格、ステイルメイト、50手、同一局面3回、駒不足 |
| 5五将棋 | 持ち駒、成り、二歩・打ち歩詰め・行き所のない歩の禁止、千日手 (先手負け、連続王手は王手側の負け) |
| エアホッケー | マルチタッチで二人同時に操作。5/7/10点先取 |

ボードゲームには「待った」と「最初から」があります。

## 遊び方

1. iPhone の Safari でページを開く
2. 共有ボタン →「ホーム画面に追加」をすると、全画面のアプリとして起動でき、一度開けばオフラインでも遊べます
3. メニューの「向かい合わせモード」をオンにすると、テーブルをはさんで座ったときに上側の人の表示が逆さになります (チェスの黒駒、将棋の後手の持ち駒、ヨットとヒット&ブローの手番の画面など)

## 公開のしかた (GitHub Pages)

ビルドは不要です。リポジトリの **Settings → Pages → Build and deployment** で
「Deploy from a branch」を選び、このファイルがあるブランチと `/ (root)` を指定すると
`https://<ユーザー名>.github.io/asobi/` で遊べるようになります。

## 開発

```sh
npx serve .        # http://localhost:3000 で確認 (ES Modules なので file:// では動きません)
npm test           # ルール部分のテスト (チェス・5五将棋の perft など)
```

- `js/games/*-logic.js` … 各ゲームのルール (DOM に依存しない)
- `js/games/*.js` … 各ゲームの画面
- `js/ui.js` … 共通の部品・設定・効果音
- `sw.js` … オフライン用キャッシュ。ファイルを追加・更新したら `VERSION` を上げてください
